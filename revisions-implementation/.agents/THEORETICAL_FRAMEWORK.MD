## 🧩 Core Revised Modules

### 1. Product Customization Engine
- **Purpose**: Enables customers to define unique product specifications.
- **Data Flow**: Captures user parameters -> Generates material estimates -> Feeds into the Appointment/Quote system.

### 2. Geospatial Scope Filter (Cavite & Laguna)
- **Purpose**: Restricts system operations and appointment bookings to the serviceable areas of Cavite and Laguna.
- **Logic**: Validates user addresses against a predefined regional boundary during the appointment booking phase.

### 3. Production Progress Tracker (%)
- **Purpose**: Provides real-time visibility into the project lifecycle.
- **Features**:
    - **Granular Updates**: Welders update completion percentage (e.g., 20% milestones).
    - **Expectation vs Reality**: Visual comparison tool for customers to see progress photos vs. original designs.

### 4. Material Sourcing Intelligence
- **Purpose**: Automates decision-making based on material availability.
- **Logic**: Differentiates between locally sourced (PH) and international materials, triggering specific workflows for project acceptance and procurement timelines.

### 5. Sales & Financial Analytics
- **Purpose**: Comprehensive financial oversight.
- **Capabilities**:
    - **Multi-Period Reporting**: Daily, weekly, monthly, and yearly sales tracking.
    - **Payment Verification**: Dedicated workflow for verifying GCash uploads and cash transactions.

## 🔄 Revised Data Interaction Model

| Actor | Primary Interactions (Revised) | Output / Impact |
| :--- | :--- | :--- |
| **Customer** | Customizes products, checks available dates, tracks progress (%), uploads GCash proof. | Transparent project lifecycle & faster payment verification. |
| **Staff (Cashier)** | Manages appointments (Cavite/Laguna only), assigns materials/staff, validates sourcing. | Efficient resource allocation & scope management. |
| **Staff (Welder)** | Updates project %, timeline, and material usage. | Accurate real-time tracking for customers. |
| **Admin** | Monitors staff performance, analyzes multi-period sales, manages user accounts. | Data-driven business scaling and operational oversight. |

## 📈 Theoretical Foundation
This framework is built on **Agile Project Management** principles, adapted for a manufacturing/welding environment. By emphasizing real-time feedback (Progress Tracker) and strict resource validation (Material Intelligence), the system reduces operational bottlenecks and increases customer trust.
